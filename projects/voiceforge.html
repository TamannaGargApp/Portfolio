The idea

Voice tools in both directions, in one place.

Most tools either read text aloud or transcribe speech, rarely both. VoiceForge does both and connects them: a transcript can be edited and sent straight to the Studio to be spoken again. Every user has their own account, and every generation and transcript is saved to their history.

What I built

  • A FastAPI backend with routes for auth, text-to-speech, speech-to-text and history.
  • Text-to-speech with Edge neural voices, speed and pitch control, and MP3 or WAV export.
  • Offline speech-to-text with faster-whisper, with language auto-detection.
  • Email and Google sign-in with bcrypt password hashing and JWT tokens.
  • A no-build HTML, CSS and JavaScript frontend, and Docker Compose with Nginx to run it all.

How it works

From text to voice, and back again

The browser talks to the backend through an Nginx reverse proxy. Each request carries a JWT, so every result is saved to the right user's history in MongoDB.

1 · Text to speech

  1. User writes text in the Studio and picks a voice
  2. Speed (0.5× to 2×) and pitch (−10 to +10) are converted to Edge TTS rate and Hz
  3. Edge TTS generates the audio as MP3
  4. Optional WAV export with pydub and ffmpeg
  5. The audio file is returned and the request is saved to history

2 · Speech to text

  1. Record with the microphone or drag in an audio file
  2. Backend checks the file is not empty and is under 25 MB
  3. faster-whisper transcribes on the CPU with int8 and voice activity detection
  4. Language is auto-detected unless the user picks one
  5. Text, language and duration are returned and saved

3 · Accounts & history

  1. Register with email and password, or continue with Google
  2. Backend issues a JWT that expires after 24 hours
  3. Every API route checks the Bearer token
  4. History and transcripts are stored per user in MongoDB
  5. Search past generations from the History page

Offline transcription

Whisper runs locally, so audio is never sent to a third-party API. The model downloads once and is reused.

Choose speed or accuracy

One setting switches the Whisper model from tiny to large-v3, trading speed for accuracy.

Round trip

Copy a transcript, download it as .txt, have it read aloud, or open it in the Studio to turn it back into speech.

Developer API

Security

Accounts that are safe by default.

Google sign-in tokens are verified on the backend before an account is created or logged in, and secrets stay in an .env file that is never committed.

  • Passwords hashed with bcrypt
  • JWT signed with HS256, 24-hour expiry
  • Google ID token verified on the server
  • One-time nonce checked on Google sign-in
  • Bearer token required on every API route
  • Upload size limit on audio files
