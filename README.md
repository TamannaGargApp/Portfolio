# Tamanna Garg · Portfolio

Plain HTML, CSS and JavaScript. No build step, works directly on GitHub Pages.

## Publish on GitHub Pages
1. Create a repository (e.g. `TamannaGargApp.github.io` for a site at https://tamannagargapp.github.io).
2. Upload everything in this folder to the repository root (`index.html` must be at the top level).
3. In the repo, open **Settings → Pages**, set **Source** to "Deploy from a branch", branch `main`, folder `/ (root)`, and save.

## Structure
- `index.html` – all page content
- `css/style.css` – styles
- `js/main.js` – mobile menu, scroll animations, active nav link
- `assets/` – images and favicon
